# 島民公僕 Island Governor

繁體中文、低多邊形 3D 社區政治與治理遊戲 MVP。TypeScript + Vite + Three.js；無後端、無付費素材。

## 開發

Node.js 24：`npm ci`、`npm run dev`。`npm test` 執行遊戲規則測試，`npm run build` 執行 TypeScript 檢查並產生 dist。

## 新手教學

新遊戲開啟「幸福里小幫手」，解釋居民身分與預算，並依實際進度逐步引導調查、政見、居民走訪、選舉、工程、時間加速、事件及驗收。按教學卡的引導按鈕可前往對應頁面，金色外框標示下一個操作。可選「先自由探索」隱藏教學，再從旅程或設定重新開啟；進度與教學偏好隨存檔保存。既有存檔也能從目前進度接著教學。

## 遊玩

主選單開始／繼續。點擊地圖菱形或「旅程」議題列表，調查至少三項問題並選政見；居民頁可走訪 24 位居民。至少三項政見、40 CP 可參選。投票由群體偏好、走訪、信用與承諾成本決定，只有 ±1.5 分的小幅擾動。

當選取得 $120,000、6 位工程人員。選議題、規模、人力與材料，依序預算編列 → 人力 → 上級核准 → 開工。管理視角提供暫停、1/3/8 倍速（1 倍每 12 秒一天）。重大事件自動暫停；工程竣工後手動驗收與公布成效，獲得 XP 並保存城市變化。財政頁提供任期最高 $60,000 補助。敗選保留 XP、7 天冷卻，每天恢復 4 CP。

WASD：探索移動／俯瞰平移。拖曳：旋轉；Shift 拖曳：平移；滾輪：縮放。V 切換視角，E 與附近居民互動。手機以虛擬搖桿和按鈕操作。進度儲存在瀏覽器 localStorage，每 5 秒及重要操作自動保存。新遊戲會覆寫同裝置存檔。

## MVP 範圍與限制

完整可玩職位為里長；區長／市長／總統有資格資料與預覽，尚未提供選舉治理。具五議題與各三種政策、24 位程序化居民、1,200 人分群選民、五類施工事件、財政人力與七階段工程、公園／路燈／排水視覺更新。事件採簡化的付費處理或工期換取協調；行政能力目前固定，無招聘系統。NPC 為簡單區域散步，沒有完整導航、交通模擬或室內探索。行動裝置與真實 GPU 的視覺驗收應在部署後進行。沒有音效與多人連線。

## 自由提案與景觀改善

在尚未規劃工程的議題中，先完成調查，再於「這個地方，你想怎麼改變？」輸入 8～600 字。按「整理我的提案」，核對並修改六類項目：樹木、花圃、長椅、步道、庭園燈、清潔。確認後列入競選承諾；當選後按既有工程流程規劃、支付預算、分配人力、施工與驗收。

這是免費、前端執行的關鍵字規則，不是生成式 AI。可以處理部分否定用語，但仍需要玩家核對清單；不支援內容會提示或不列入建設。選址目前使用五個固定治理地點，尚未開放任意空地選址。居民意見為規則式回饋，尚無自由對話模型。

美化追加費用與維護費納入原有財政；提交文字不會直接獎勵 XP。自行提案兌現時額外 +20 XP、+2 政治信用，每項工程僅一次。工程規劃時保留一份提案快照，避免中途修改或重複領獎。自行提案也會計入選舉的承諾成本評估。

完工後依確認項目生成景觀，完整公園方案包含整齊步道、綠籬、花圃、休憩座椅、植樹、庭園燈與小水景；原有存檔已完工工程也會套用標準改善景觀。「看看整治後的模樣」可直接聚焦成果。選項與完工狀態均保存於 localStorage。

## 公園道具庫與自由擺設

當選里長並完成曦光公園工程、驗收及公布成效後，點畫面「♧ 布置公園」。擺設時暫停遊戲時間，聚焦公園；原有操作介面暫時隱藏，退出後恢復鏡頭。

提供植栽、遊具、水景、休憩、裝飾與鋪面共 20 種程序化模型，卡片顯示實際模型縮圖、價格、尺寸與每日維護。選道具、點草地定位、旋轉後明確確認；點已放置物件可移動、旋轉或收回。R 旋轉、Esc 取消，手機使用同一組明確按鈕。取消或退出會放棄尚未確認的操作。

可布置範圍為公園中央 14×12 公尺草地，半公尺吸附、90 度旋轉。以旋轉後矩形占地檢查邊界與重疊；步道與其他設施可以邊緣相接，但不能疊放。外圍地景、道路及建築不列入可布置範圍。既有公園固定遊具與完工裝飾轉由可編輯清單生成；外圍街邊設施已移出範圍。

確認新購才扣款並增加維護，移動旋轉免費；收回退原付款的 50%，減回該物件維護費。原工程附帶設施免費轉入，不退款，其維護已包含工程原有維護費。擺設不發放 XP 或信用。費用、退款記入原財政紀錄。確認變更立即存檔，保存唯一 ID、種類、公園內座標、旋轉與原付款；舊存檔依原工程／自行提案清單一次初始化，其他進度保留，清空配置也不會重建預設物件。

模型按顏色合併並快取共用幾何與材質，重建配置不釋放共用資源；預覽獨立材質在取消、移動與退出時釋放。縮圖共用單一 WebGL renderer。此版本只開放曦光公園，不提供任意角度、步道疊放或其他區域編輯。


驗證：`npm test` 包含放置、財政、舊存檔與模型占地／共用資源測試。瀏覽器測試先執行 `npx playwright install chromium`，另開終端啟動 `npm run dev -- --port 5173`，再執行 `npm run test:browser`。測試使用獨立瀏覽器與已完工測試存檔，涵蓋桌面放置、旋轉、移動、收回、取消、重載，以及 390×844 手機尺寸放置與操作，截圖留在忽略版控的 `work/`。既有 Pages workflow 仍執行規則測試與建置；不在 CI 額外安裝瀏覽器。
