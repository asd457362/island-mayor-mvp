# 島民公僕 Island Governor

繁體中文、低多邊形 3D 社區政治與治理遊戲 MVP。TypeScript + Vite + Three.js；無後端、無付費素材。

## 開發

Node.js 24：`npm ci`、`npm run dev`。`npm test` 執行遊戲規則測試，`npm run build` 執行 TypeScript 檢查並產生 dist。

## 遊玩

主選單開始／繼續。點擊地圖菱形或「旅程」議題列表，調查至少三項問題並選政見；居民頁可走訪 24 位居民。至少三項政見、40 CP 可參選。投票由群體偏好、走訪、信用與承諾成本決定，只有 ±1.5 分的小幅擾動。

當選取得 $120,000、6 位工程人員。選議題、規模、人力與材料，依序預算編列 → 人力 → 上級核准 → 開工。管理視角提供暫停、1/3/8 倍速（1 倍每 12 秒一天）。重大事件自動暫停；工程竣工後手動驗收與公布成效，獲得 XP 並保存城市變化。財政頁提供任期最高 $60,000 補助。敗選保留 XP、7 天冷卻，每天恢復 4 CP。

WASD：探索移動／俯瞰平移。拖曳：旋轉；Shift 拖曳：平移；滾輪：縮放。V 切換視角，E 與附近居民互動。手機以虛擬搖桿和按鈕操作。進度儲存在瀏覽器 localStorage，每 5 秒及重要操作自動保存。新遊戲會覆寫同裝置存檔。

## MVP 範圍與限制

完整可玩職位為里長；區長／市長／總統有資格資料與預覽，尚未提供選舉治理。具五議題與各三種政策、24 位程序化居民、1,200 人分群選民、五類施工事件、財政人力與七階段工程、公園／路燈／排水視覺更新。事件採簡化的付費處理或工期換取協調；行政能力目前固定，無招聘系統。NPC 為簡單區域散步，沒有完整導航、交通模擬或室內探索。行動裝置與真實 GPU 的視覺驗收應在部署後進行。沒有音效與多人連線。
